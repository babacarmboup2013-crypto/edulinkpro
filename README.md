# EduLink Pro

Site déployé sur GitHub Pages.

## Déploiement

1. `npm install`
2. `npm run build`
3. `git add .`
4. `git commit -m "Deploy site"`
5. `git push origin main`

## GitHub Pages

- Branche de publication : `gh-pages`
- Fichier de workflow : `.github/workflows/deploy.yml`

## Configuration GitHub

- Assure-toi que GitHub Pages est activé sur la branche `gh-pages`.
- Si le repo est https://<username>.github.io/JSX1, l'URL finale sera https://<username>.github.io/JSX1/.
